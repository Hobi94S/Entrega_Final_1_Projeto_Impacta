# Impacta

Atividade da disciplina de **Programação em Linguagem Orientada a Objetos Avançada**, do curso da **Unifacisa**.

## Sobre o projeto

O **Impacta** é um sistema para apoiar o engajamento de estudantes em causas socioambientais. A aplicação deverá permitir o cadastro e o gerenciamento de ações comunitárias, o controle de inscrições e o acompanhamento do histórico de participação dos alunos.

## Objetivo

Aplicar conceitos avançados de programação orientada a objetos na implementação das classes responsáveis pelas regras e funcionalidades do sistema.

## Observação

Não é necessário implementar uma classe com método `main`. Devem ser desenvolvidas apenas as classes do sistema, incluindo a classe `Impacta`, cujas funcionalidades serão invocadas externamente.
